# Taller securechat

Chat TCP que utiliza criptografia simetrica y asimetrica para proteger mensajes

## Requerimientos:

- Python 3.14
- Biblioteca `cryptography`

## Para iniciar:

- Abrir 2 terminales y ejecutar:

```bash
    python server.py
```

```bash
    python client.py
```

- Comienza a hablar en el chat

### Escribe 'salir' para terminar
